# 12.3 AKS Presentation Guide

> **Purpose**
>
> This guide explains how to present the AKS enabled by Azure Arc
> implementation during Microsoft accreditation, customer
> demonstrations, architecture reviews, and internal knowledge sharing
> sessions.

------------------------------------------------------------------------

# 1. Presentation Objective

Demonstrate a successful deployment of AKS enabled by Azure Arc on Azure
Local and validate:

-   Azure Arc integration
-   Kubernetes deployment
-   Networking
-   Workload validation
-   Platform health
-   Operational readiness

------------------------------------------------------------------------

# 2. Target Audience

-   Microsoft Accreditation Assessors
-   Solution Architects
-   Cloud Architects
-   Customers
-   Technical Review Boards

------------------------------------------------------------------------

# 8. Common Mistakes

Do NOT

-   Show subscription IDs
-   Show tenant IDs
-   Show Cloud Shell failures
-   Show blank monitoring dashboards
-   Show failed deployment screenshots
