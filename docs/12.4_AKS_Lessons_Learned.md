# 12.4 AKS Lessons Learned

> **Purpose**
>
> This document captures the technical, operational, and architectural
> lessons learned during the implementation of AKS enabled by Azure Arc
> on Azure Local.

------------------------------------------------------------------------

# 1. Executive Summary

The implementation successfully demonstrated that AKS enabled by Azure
Arc can be deployed and validated on Azure Local using a minimal
topology. The project also highlighted several operational
considerations that are valuable for future production deployments.

------------------------------------------------------------------------

# 2. Technical Lessons

## Azure Local

-   Always validate Azure Local health before deploying AKS.
-   Verify cluster nodes, storage, and Cloud Witness before
    troubleshooting Kubernetes.
-   Existing workloads should remain healthy after AKS deployment.

## Azure Arc

-   Arc provides a consistent Azure management experience.
-   Connected status should be validated before any workload deployment.

## AKS Deployment

-   Portal deployment is ideal for learning the deployment workflow.
-   Minimal topology is sufficient for proof-of-concept environments.
-   Production environments should consider multiple worker nodes and
    HA.

------------------------------------------------------------------------

# 3. Networking Lessons

-   Plan IP ranges before enabling MetalLB.
-   Reserve a dedicated address pool for LoadBalancer services.
-   Keep the control plane and LoadBalancer ranges separate.
-   Validate application access from the Azure Local network.

------------------------------------------------------------------------

# 4. MetalLB Lessons

-   Portal installation may not always succeed in lab environments.
-   Azure CLI provided a reliable deployment path.
-   Validate provisioning state after configuration.

------------------------------------------------------------------------

# 5. Monitoring Lessons

-   Azure Monitor Containers extension can deploy successfully even when
    telemetry is not immediately available.
-   Separate monitoring validation from workload validation.
-   Use Log Analytics queries to validate ingestion.

------------------------------------------------------------------------

# 6. Evidence Collection Lessons

-   Capture screenshots immediately after validation.
-   Sanitize all sensitive information.
-   Maintain a consistent naming convention.
-   Record successful validation before starting the next task.

------------------------------------------------------------------------

# 7. Documentation Lessons

-   Keep implementation and troubleshooting documents separate.
-   Document actual observations rather than assumptions.
-   Record both successful outcomes and known limitations.

------------------------------------------------------------------------

# 8. Production Recommendations

-   Use production-sized node pools.
-   Implement high availability.
-   Configure backup and disaster recovery.
-   Enable governance and policy.
-   Validate monitoring before production sign-off.

------------------------------------------------------------------------

# 9. Future Improvements

-   Azure Virtual Desktop
-   GitOps
-   Ingress Controller
-   Azure Policy for Kubernetes
-   Defender for Containers
-   Production monitoring dashboards

------------------------------------------------------------------------

# 10. Key Takeaways

-   Azure Local platform remained healthy throughout the deployment.
-   AKS deployment completed successfully.
-   MetalLB provided functional external connectivity.
-   The sample application validated end-to-end networking.
-   Monitoring telemetry remains a follow-up activity.

------------------------------------------------------------------------

# 11. Conclusion

The lab achieved its primary objective of demonstrating a working AKS
enabled by Azure Arc deployment on Azure Local. The implementation
provides a reusable reference architecture and deployment approach for
future hybrid Kubernetes environments.
